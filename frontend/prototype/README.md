# 동작 프로토타입 (정적 데모)

브라우저에서 파일을 바로 열면 된다. 서버 불필요.

| 파일 | 내용 |
|---|---|
| `ZeroPick_프로토타입.html` | 고객 쇼핑몰 — 상품 515건(실데이터·실이미지), 필터, 추천순 정렬, 비교, 장바구니, 모의결제, 챗봇, 회원가입/로그인 |
| `ZeroPick_관리자.html` | 관리자 콘솔 — 성과 대시보드, 이벤트 로그 (고객 페이지 행동이 실시간 반영, Kafka 흉내) |

- 고객 페이지에서 클릭·담기·주문하면 **관리자 이벤트 로그에 Kafka로 발행될 payload가 그대로 쌓인다** — 이벤트 구현 시 이 형태 참고 (`docs/avro/` 스키마와 동일 구조).
- 각 화면이 호출할 API는 화면 하단·산출물 화면기획서에 기재. 실제 프론트는 별도 React 앱으로 개발 예정.
- 이 폴더는 데모 참조용 — 여기 코드를 실서비스에 쓰지 않는다.
